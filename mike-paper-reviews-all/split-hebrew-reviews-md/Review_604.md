Moving the Operating System into the Latent Space Mike's daily paper review: 12.04.26 NEURAL COMPUTERS We typically treat neural networks and computers as distinct entities where models execute inside conventional operating systems. This paper proposes collapsing that boundary entirely by learning a single latent runtime that unifies computation, memory, and input-output operations. The authors investigate whether a video model can internalize an interactive interface directly from raw input traces without accessing underlying program state.

The system tracks a persistent latent runtime state updated continuously via a diffusion process, a generative framework that iteratively refines random noise into structured outputs. Inputs consist of user actions like keystrokes or pointer coordinates alongside visual observations. The model outputs the next visual frame of the interface. This single updating representation functions simultaneously as working memory and the execution environment.

The authors construct two prototypes using a diffusion transformer video model as the base architecture. For terminal environments, the model receives a text prompt and an initial visual frame. For desktop environments, the system ingests a synchronized stream of interface pixels and user actions. The desktop implementation processes actions by converting discrete keyboard and mouse events into a compressed semantic vocabulary, grouping individual keystrokes or clicks into explicit event types.

To bridge actions and visual generation, the system aligns asynchronous user inputs to the temporal grid of the video. The authors encode interface actions into dense representations and test multiple ways to inject these features into the video generator. One specific injection approach feeds action features directly into the transformer blocks via a dedicated cross-attention mechanism, a network operation that allows the visual layers to directly query the user input stream. This structural design forces the network to attend to user inputs alongside visual features at every layer.

The evaluation signal relies entirely on pixel reconstruction and temporal contrastive alignment. The system generates future interface frames based on the action stream, and the training error is calculated against the ground truth video of the recorded interaction. To address the challenge of tracking small but critical interface elements like the mouse pointer, the desktop prototype uses an explicit visual masking strategy. The system renders an artificial cursor over a blank background and feeds this isolated cursor image into the model as an additional conditioning signal. This forces the model to process the pointer location as a distinct visual object rather than an abstract coordinate sequence.

Prior interactive world models predict environment dynamics based on discrete action spaces but maintain a conceptual separation between the model and the execution state. Similarly, computer-use agents operate by sending text commands to external application programming interfaces. This paper changes the paradigm by configuring the generative video model to act as the executing environment itself. Instead of predicting what an external system will do, the latent state of the diffusion model carries the entire executable context. The authors also move away from treating user inputs as uninterpreted event streams. By discretizing raw mouse movements and keystrokes into structured semantic actions and injecting them deep into the transformer attention blocks, they establish a direct pathway between specific user intents and localized visual updates.

The proposed design heavily assumes that learning interface dynamics from pixels is sufficient to capture underlying computational logic. Because the method lacks a native symbolic reasoning module, it must rely entirely on visual pattern matching to simulate execution. This structural choice exposes the system during operations requiring rigorous sequential logic, such as arithmetic or complex command line interactions. The approach also assumes access to perfectly synchronized, high-quality demonstration data. Training on noisy or uncurated interaction logs can inject erratic visual artifacts and spurious pointer movements into the generated output. Furthermore, the reliance on continuous pixel-level generation means the system cannot guarantee discrete state preservation, exposing it to drifting layouts and hallucinated interface elements during prolonged interactions.

Computational demands scale with the size of the underlying video generator and the length of the required interaction history. Maintaining the latent runtime state requires continuous autoregressive generation, where each new state depends sequentially on the previous outputs, which incurs significant inference overhead compared to conventional symbolic execution.
