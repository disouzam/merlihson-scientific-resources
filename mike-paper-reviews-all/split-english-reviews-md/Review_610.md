Review 610: It's not enough for an LLM to be right: from a single correct answer to a collection of ways of thinking.
Omri’s and Mike’s Daily Paper, 13.05.26, Review 610
Poly-EPO: Training Exploratory Reasoning Models

In recent years, RL has become one of the central tools for improving the reasoning abilities of language models. One especially prominent approach is RLVR, training with a verifiable reward, usually based on a simple question: is the final answer correct or not? This approach significantly improves Pass@1, a metric that checks whether the model reached the correct answer in a single attempt, or more simply, the accuracy of the answer the model gives in greedy mode. But it also comes with a real cost: it tends to collapse the diversity of the model’s reasoning paths. Instead of preserving several different solution strategies, the model quickly learns to stick to a small number of high-reward patterns. This creates a basic tradeoff: on one hand, greedy accuracy improves; on the other hand, exploration decreases, as reflected in Pass@k, a metric that checks whether the model manages to reach the correct answer when it is allowed k different attempts rather than just one.

To address this problem, the authors propose Poly-EPO, a method that shifts the center of gravity from a single answer to sets of answers. For each question, the model generates N answers, builds subsets of size n from them - that is, “N choose n” possible sets - and assigns each set a shared score based on a combination of correctness and diversity of solution strategies.

In standard RL, the objective is to maximize the expected reward of a single answer sampled from the model: for a question x from the dataset D, the model generates an answer y according to its policy and receives a reward r(x, y). In contrast, Poly-EPO proposes a set-level objective. The score of a set is computed as the product of two components: the average reward of the answers inside the set, and a diversity measure over the solution strategies in that set. Roughly:

set score = average correctness of the answers × diversity of solution strategies

The diversity of strategies is computed by counting the number of different clusters that appear in the set, divided by the size of the set. If a set of size n contains answers that belong to several different clusters, its diversity is higher. These clusters are not defined by keywords or superficial phrasing differences, but by using an LLM-as-a-judge: an additional language model that receives all N answers sampled for the same question and clusters them according to their reasoning strategy. This is an important point in the paper: the diversity they try to measure is not “the model wrote it a bit differently,” but an attempt to identify whether the answers truly use different solution approaches, for example an algebraic solution versus a combinatorial one.

One interesting consequence of this definition is what the authors call optimistic exploration. to be precise: in the standard reward setup used in the paper, an incorrect answer usually receives 0, not a negative score. So it does not “penalize” the set; it simply does not add correctness. But if that incorrect answer contributes a new solution strategy to a set that also contains correct answers, it can increase the diversity component of the set - and therefore eventually receive a positive advantage. Not because it is correct on its own, but because it participated in a set that received a relatively good score.

Implementation-wise, for each question the method samples N answers, constructs subsets of size n, and assigns each subset a score based on the combination of average correctness and strategy diversity. Then each subset is compared to the average score of all subsets: a set above the average receives positive advantage, and a set below the average receives negative advantage. This credit is then passed back to each answer according to all the sets in which it appeared, this is its marginal advantage. The resulting signal can then be plugged into a regular RL update, such as GRPO, without needing to build an entirely new training algorithm from scratch.

In terms of results, the main advantage of Poly-EPO appears primarily in Pass@k. As the number of samples at test time increases, Poly-EPO makes better use of the additional samples and shows a significant improvement compared to standard GRPO and baselines that add a simpler diversity bonus. At the same time, the paper also reports Pass@1 results, where Poly-EPO remains competitive with standard RL methods. This is important because the paper’s claim is not simply “we sacrifice greedy accuracy for diversity,” but something more subtle: it is possible to preserve strong single-answer performance while also preventing the collapse of solution diversity.
