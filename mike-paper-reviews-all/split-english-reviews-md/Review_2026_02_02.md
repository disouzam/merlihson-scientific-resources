# Making Infinity Sparse: LongCat's Layer-Level LotteryMike’s Daily Paper Review: 02.02.26


Efficient Context Scaling with LongCat ZigZag Attention

The quadratic complexity of attention mechanisms remains the main bottleneck for long context windows appearing, for example, in agentic applications. While architectural changes like linear attention or SSM models such as Mamba attempt to bypass this, the reviewed paper proposes a methodological intervention for existing full attention models. The authors developed LongCat ZigZag Attention (or LoZA), a sparse attention method designed to transform dense Multi-Head Latent Attention (MLA) architectures into sparse hybrid models during mid-training.

The novelty here is not necessarily the sparse pattern itself, but the discovery and implementation process in a "calibrate-then-train" style that identifies and eliminates redundant dense computation at the layer level rather than the attention head level.

The Calibration Mechanism (Not Fine-Tuning!)

LoZA views the transition from full to sparse attention as a feature that can be discovered during training. The process begins with a calibration phase applied to an existing model that has undergone mid-training (the authors used the LongCat-Flash model, built on DeepSeek’s MLA).

For every attention layer, the authors define a learnable scalar, alpha ($\alpha$), between zero and one. During calibration, the layer output becomes a weighted sum between the original full attention output and a candidate sparse attention output. This candidate sparse output uses Streaming Sparse Attention (SSA), a pattern where every query token (Q) "sees" only a fixed number of initial token blocks and several token blocks close to it.

The model is frozen while only alpha is trained on the calibration data. This process effectively measures the sensitivity of each layer to long-range dense dependencies. Mathematically, a low alpha value indicates that the layer's contribution is dominated by the sparse component without significant loss in performance. This is reminiscent of the Lottery Ticket Hypothesis (which claims that in every network there is a small sub-network with the same performance as the large network) and identifies a sub-network (the sparse one) that can match the full network in terms of performance.

Layer-Level Sparsity vs. Head-Level Sparsity

After the calibration quantifies layer sensitivity, LoZA begins to "prune the model density." The 50% of layers with the lowest alpha values are permanently switched to sparse, while the remaining layers retain full quadratic attention.

The specific decision to enforce sparsity at the layer level represents a significant departure from previous developments like Duo-Attention, which implement sparsity at the attention head level. The authors argue that head-level sparsity introduces critical inefficiency at the system level. In a distributed environment, head-level sparsity leads to computational imbalance between parallel ranks (stragglers) and necessitates complex scheduling algorithms in GPU kernels to handle heterogeneous workloads. This can cause warp divergence in GPUs (divergence and desynchronization in thread execution), a state where threads within a block split in their execution paths.

In contrast, LoZA’s layer-level approach ensures that within each layer, computational density is uniform. The kernel sees either full attention or sparse attention for the entire tensor, allowing for easier synchronization.

The Sparse Topology and Mid-Training

The sparse pattern implemented in the paper for the selected layers works as follows: It preserves a fixed number of Sink blocks (which is global attention) and a sliding window of several blocks adjacent to the token for which attention is being computed. The paper uses a block size of 128 tokens, with one Sink block and 7 local blocks, creating a local receptive field of 1,024 tokens for the sparse layers.

The final step is the "ZigZag" training itself. Unlike post-training quantization methods that degrade performance, LoZA integrates the sparsification into the mid-training phase. The model, now architecturally hybrid, undergoes further training on a mixture of reasoning data, agentic data, and long-context data. This stage allows the remaining full attention layers and the new sparse layers to adapt to the new architecture (a combination of full and sparse). To enable context scaling up to a million tokens, this training is combined with YaRN (an efficient method for extending the context window in language models).
